Component Tree for Jira

Jira components are a flat list. Component Tree turns them into a tree, so you can find everything in a branch at once and see where each work item sits.

Read the docs Getting started
  • Arrange components into parents and children by drag and drop.
  • Search a whole branch with componentBranch in any filter or board.
  • See each work item's full path, like Platform / Payments / Refunds.
  • Runs on Atlassian. Nothing leaves your Jira site.
